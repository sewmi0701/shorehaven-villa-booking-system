# Project report — draft

The included `../project_report.pdf` is **four pages**. It covers introduction/objectives, interface concepts, ERD, core functions, tests and reflections. It is explicitly a **draft** and must be personalised with the student's name/ID, genuine screen captures from the running system, actual testing evidence and reflections.

To regenerate, put `home.png`, `rooms.png`, `booking.png`, `admin.png` in `screenshots/` and run `python tools/build_report.py` from the project root in an environment with ReportLab and CairoSVG installed. Manual PDF replacement is also fine. Keep the final report to five pages or less.
